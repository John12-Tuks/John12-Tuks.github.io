Today I started building my own technical blog using GitHub Pages and Jekyll.

The idea is simple: I want a place where I can document the software I build, the technologies I'm learning and the problems I encounter.

## Why GitHub Pages?

I wanted the entire site to live alongside my code.

Using GitHub Pages means the source code, blog posts and website are all part of the same development workflow.

That gives me a simple process:

```text
Write
  ↓
Commit
  ↓
Push
  ↓
GitHub Actions
  ↓
Published website
