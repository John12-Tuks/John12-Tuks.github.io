# About Me

I'm Tokelo, a computer science student interested in software engineering, cybersecurity, artificial intelligence and systems.

I'm using this website as a technical journal to document the things I build and the things I learn.

## What I Enjoy Building

I'm particularly interested in:

- Backend systems
- APIs
- Databases
- Cloud applications
- Android development
- Cybersecurity
- Machine learning
- Linux and systems programming

## Why This Blog Exists

A lot of learning disappears after the project is finished.

I want this site to be different.

Instead of only documenting the final result, I want to record the process:

**Idea → Design → Implementation → Problems → Solutions → Lessons**

That includes failed experiments, bugs, architectural decisions and things I would do differently.

## Long-Term Goal

My goal is to become a strong software engineer capable of working across application development, backend systems, cybersecurity and eventually lower-level computing.

This site is essentially the public logbook of that journey.
